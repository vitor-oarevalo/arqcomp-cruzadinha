# 🕵️ Detetive da Arquitetura

**Detetive da Arquitetura** é um jogo educativo desenvolvido em HTML, CSS e JavaScript, com o objetivo de testar e reforçar conhecimentos sobre componentes e conceitos da arquitetura computacional.

O jogador assume o papel de um investigador contratado para solucionar um grande mistério: identificar os componentes responsáveis pelo funcionamento de um computador.

## 🌐 Acesse o jogo

[**Jogar Detetive da Arquitetura**](https://vitor-oarevalo.github.io/arqcomp-cruzadinha/)

## 🎮 Como jogar

1. Na tela inicial, leia a proposta apresentada pelo diretor da empresa.
2. Clique em **Aceitar o desafio** para iniciar a investigação.
3. Analise as 16 pistas disponíveis no mural.
4. Digite o nome do componente correspondente a cada pista.
5. Conforme os componentes forem reconhecidos, as imagens serão reveladas.
6. Preencha todos os campos para liberar a verificação.
7. Confira seu resultado e descubra quanto receberia pelo trabalho!

## 🔎 Lista de palavras e pistas

## AS RESPOSTAS ESTÃO ABAIXO, NÃO OLHE CASO QUEIRA JOGAR

Abaixo estão os 16 componentes e conceitos utilizados no jogo:

| Nº | Palavra | Pista |
|:---:|---|---|
| 01 | **CPU** | Componente que executa instruções, faz cálculos e coordena as tarefas de um computador. |
| 02 | **ULA** | Componente que executa operações matemáticas e lógicas em um processador. |
| 03 | **UC (Unidade de Controle)** | Componente que busca, decodifica e coordena a execução de instruções. |
| 04 | **Registradores** | Pequenas memórias extremamente rápidas de um processador. |
| 05 | **RAM** | Memória temporária e volátil do computador. |
| 06 | **ROM** | Memória permanente e não volátil, de apenas leitura, que guarda a BIOS. |
| 07 | **EEPROM** | Memória não volátil que permite alterar um byte por vez. |
| 08 | **Flash** | Memória não volátil que permite gravar dados em blocos grandes. |
| 09 | **Cache** | Memória muito rápida integrada no próprio chip do processador. |
| 10 | **Memória de Massa** | Dispositivos usados para armazenar grandes quantidades de dados. Não volátil e mais lento. |
| 11 | **DMA** | Recurso do hardware que permite que dados sejam escritos diretamente na RAM. |
| 12 | **Address Bus** | Conjunto de linhas condutoras da CPU para enviar endereços de memória. |
| 13 | **Data Bus** | Conjunto de conexões que transfere dados entre componentes de um processador. |
| 14 | **Microcontrolador** | Computador compacto integrado em um único chip. |
| 15 | **Dual Core** | CPU que possui dois núcleos de processamento independentes em um hardware. |
| 16 | **Quad Core** | CPU que possui quatro núcleos de processamento independentes em um hardware. |

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, animações e responsividade.
- **JavaScript:** lógica do jogo, validação das respostas, pontuação e interação com o jogador.
